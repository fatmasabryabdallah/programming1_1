Loop

الـ Loop تستخدم لتكرار تنفيذ مجموعة من الأوامر أكثر من مرة.

Definition

الـ Loop هي طريقة لتكرار مجموعة من التعليمات البرمجية عدة مرات بدلًا من كتابة نفس الكود بشكل متكرر.

من أشهر أنواع الـ Loops في Java: for و while و do while.

For Loop 
for (int i = 1; i <= 5; i++) {
    System.out.println(i);
}

يبدأ المتغير i من 1 ويستمر التكرار طالما أن i <= 5، ثم تزيد قيمة i بمقدار 1 في كل مرة.

For Structure

يتكون الـ for loop من ثلاثة أجزاء: البداية، والشرط، والتغيير. 

for (initialization; condition; update) {
    // Code
}

initialization تحدد قيمة البداية، وcondition تحدد متى يستمر التكرار، وupdate تغير قيمة المتغير.

While Loop 
int i = 1;

while (i <= 5) {
    System.out.println(i);
    i++;
}

يستمر الـ while loop في التكرار طالما أن الشرط i <= 5 صحيح.

Do While 
int i = 1;

do {
    System.out.println(i);
    i++;
} while (i <= 5);

في do while يتم تنفيذ الكود مرة واحدة على الأقل قبل فحص الشرط.

Break 
for (int i = 1; i <= 10; i++) {

    if (i == 5) {
        break;
    }

    System.out.println(i);
}

تستخدم break لإيقاف الـ Loop مباشرة عند تحقق شرط معين.

Continue 
for (int i = 1; i <= 5; i++) {

    if (i == 3) {
        continue;
    }

    System.out.println(i);
}

تستخدم continue لتخطي التكرار الحالي والانتقال إلى التكرار التالي.

Nested Loop 
for (int i = 1; i <= 3; i++) {

    for (int j = 1; j <= 2; j++) {
        System.out.println(i + " " + j);
    }

}

يمكن وضع Loop داخل Loop أخرى، وهذا يسمى Nested Loop.

Important Notes
for تستخدم للتكرار مع التحكم في البداية والشرط والتحديث.
while تستمر طالما أن الشرط صحيح.
do while تنفذ الكود مرة واحدة على الأقل.
break توقف الـ Loop.
continue تتخطى التكرار الحالي.
