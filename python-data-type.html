Python Term

Data Type

أنواع البيانات في Python

Definition

Data Type ما هو الـ

الـ Data Type يحدد نوع القيمة التي يخزنها المتغير وكيف يمكن للبرنامج التعامل معها.

Example 
name = "Ammar"
age = 16
price = 19.5
is_student = True
Explanation

Python تحدد نوع القيمة الموجودة في المتغير بناءً على القيمة التي تم إسنادها إليه.

مثلًا: "Ammar" نص، 16 عدد صحيح، 19.5 عدد عشري، و True قيمة منطقية.

Common Python Data Types
str النصوص مثل "Hello"
int الأعداد الصحيحة مثل 10 و 25
float الأعداد العشرية مثل 10.5
bool قيم منطقية مثل True و False
list مجموعة مرتبة وقابلة للتعديل
tuple مجموعة مرتبة غير قابلة للتعديل
dict بيانات على شكل Key و Value
set مجموعة من القيم الفريدة غير المرتبة
Check Data Type 
age = 16

print(type(age))
Example with Different Types 
name = "Ammar"
age = 16
height = 1.75
is_student = True

print(type(name))
print(type(age))
print(type(height))
print(type(is_student))
Why Is Data Type Important?

معرفة نوع البيانات تساعدك على اختيار العمليات المناسبة والتعامل مع القيم بالشكل الصحيح داخل البرنامج.
