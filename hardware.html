Computer Term

Hardware

مكونات الكمبيوتر المادية

Definition

Hardware ما هو الـ

الـ Hardware هو جميع الأجزاء المادية في الكمبيوتر التي يمكن رؤيتها أو لمسها.

Examples 
CPU
RAM
Keyboard
Mouse
Monitor
Storage
Explanation

الكمبيوتر يحتاج إلى مكونات مادية لتنفيذ العمليات واستقبال البيانات وتخزينها وعرض النتائج.

هذه المكونات تسمى Hardware لأنها أجزاء فعلية من الجهاز.

Main Hardware Components
CPU تنفيذ التعليمات ومعالجة البيانات
RAM تخزين مؤقت للبيانات أثناء تشغيل البرامج
Storage تخزين البيانات والملفات
GPU معالجة الرسومات والعمليات المرئية
Keyboard إدخال النصوص والأوامر
Monitor عرض المعلومات والنتائج للمستخدم
Hardware vs Software
Hardware أجزاء مادية يمكن لمسها
Software برامج وتعليمات تعمل على الجهاز
