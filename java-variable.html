Variable

الـ Variable هو متغير يستخدم لتخزين قيمة يمكن استخدامها أثناء تشغيل البرنامج.

Definition

الـ Variable هو مكان يتم فيه تخزين قيمة داخل البرنامج، مثل رقم أو نص.

في Java يجب تحديد Data Type للمتغير قبل كتابة اسمه وقيمته.

Example 
int age = 16;
String name = "Ammar";

في المثال السابق أنشأنا متغيرًا باسم age لتخزين رقم صحيح، ومتغيرًا باسم name لتخزين نص.

Syntax

الشكل الأساسي لإنشاء Variable في Java هو: 

DataType variableName = value;

نكتب نوع البيانات أولًا، ثم اسم المتغير، ثم نضع القيمة بعد علامة =.

Variable Types
int لتخزين الأعداد الصحيحة.
double لتخزين الأعداد العشرية.
String لتخزين النصوص.
boolean لتخزين true أو false.
char لتخزين حرف واحد.
Change Value 
int age = 16;

age = 17;

System.out.println(age);

يمكن تغيير قيمة المتغير بعد إنشائه، طالما أن القيمة الجديدة متوافقة مع نوع البيانات.

String Variable 
String name = "Ammar";

System.out.println(name);

يمكن استخدام المتغير الذي يحتوي على نص لعرض القيمة باستخدام System.out.println().

Multiple Variables 
String name = "Ammar";
int age = 16;
double height = 1.75;
boolean isStudent = true;

System.out.println(name);
System.out.println(age);
System.out.println(height);
System.out.println(isStudent);

يمكن إنشاء أكثر من Variable داخل نفس البرنامج، ولكل متغير نوع واسم وقيمة.

Important Notes
Data Type يحدد نوع البيانات التي يمكن تخزينها.
Variable Name الاسم الذي نستخدمه للوصول إلى القيمة.
= تستخدم لإعطاء قيمة للمتغير.
; تستخدم لإنهاء الجملة البرمجية.
