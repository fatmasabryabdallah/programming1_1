JavaScript Term

Variable

المتغير

Definition

Variable ما هو الـ

هو اسم نستخدمه للوصول إلى قيمة مخزنة أثناء تشغيل البرنامج، ويمكن أن تتغير هذه القيمة. Variable الـ

Example 
let name = "Ammar";

console.log(name);
Explanation

"Ammar". ووضعنا داخله القيمة name في المثال السابق أنشأنا متغيرًا باسم

لعرض قيمته. console.log() لإنشاء المتغير ، ثم استخدمنا let استخدمنا

Creating Variables
let يُستخدم لإنشاء متغير يمكن تغيير قيمته
const يُستخدم لإنشاء متغير لا نعيد إسناد قيمته
var طريقة قديمة لإنشاء المتغيرات في JavaScript
name اسم المتغير الذي نستخدمه للوصول إلى القيمة
Changing a Variable 
let age = 16;

age = 17;

console.log(age);
