Method

الـ Method هي مجموعة من التعليمات البرمجية يتم تعريفها لتنفيذ مهمة معينة ويمكن استدعاؤها عند الحاجة.

Definition

الـ Method في Java هي جزء من البرنامج يحتوي على مجموعة من التعليمات التي تنفذ مهمة محددة.

تساعد الـ Methods على تنظيم الكود وإعادة استخدامه بدلًا من كتابة نفس الأوامر أكثر من مرة.

Basic Method 
static void sayHello() {

    System.out.println("Hello World");

}

sayHello();

أنشأنا Method باسم sayHello ثم استدعيناها باستخدام sayHello().

Explanation

كلمة void تعني أن الـ Method لا ترجع قيمة.

اسم الـ Method يحدد المهمة التي تقوم بها، ويجب استدعاؤها حتى يتم تنفيذ الكود الموجود بداخلها.

الأقواس { } تحتوي على التعليمات التي سيتم تنفيذها.

Parameters 
static void greet(String name) {

    System.out.println("Hello " + name);

}

greet("Ammar");

يمكن للـ Method استقبال بيانات تسمى Parameters واستخدامها داخل الـ Method.

Multiple Parameters 
static void showInfo(String name, int age) {

    System.out.println(name);
    System.out.println(age);

}

showInfo("Ammar", 16);

يمكن للـ Method استقبال أكثر من Parameter، ويمكن أن يكون لكل Parameter نوع بيانات مختلف.

Return Value 
static int add(int a, int b) {

    return a + b;

}

int result = add(5, 3);

System.out.println(result);

يمكن للـ Method إرجاع قيمة باستخدام return. في المثال السابق تقوم Method بإرجاع ناتج الجمع.

Return Types
void Method لا ترجع قيمة.
int Method ترجع عددًا صحيحًا.
String Method ترجع نصًا.
boolean Method ترجع true أو false.
String Return 
static String getName() {

    return "Ammar";

}

String name = getName();

System.out.println(name);

يمكن أن ترجع الـ Method قيمة من نوع String ثم يتم تخزين القيمة داخل متغير.

Important Notes
Method مجموعة تعليمات لتنفيذ مهمة محددة.
Parameter قيمة يتم استقبالها داخل الـ Method.
return تستخدم لإرجاع قيمة.
void تعني أن الـ Method لا ترجع قيمة.
