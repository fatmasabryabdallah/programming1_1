Input

الـ Input يستخدم لاستقبال البيانات التي يدخلها المستخدم من خلال لوحة المفاتيح.

Definition

الـ Input هو إدخال البيانات من المستخدم إلى البرنامج أثناء تشغيله.

في C# نستخدم Console.ReadLine() لقراءة النص الذي يدخله المستخدم.

Console.ReadLine() 
Console.Write("Enter your name: ");

string name = Console.ReadLine();

Console.WriteLine(name);

يطلب البرنامج من المستخدم إدخال اسمه، ثم يتم تخزين القيمة التي كتبها داخل المتغير name.

String Input 
Console.Write("Enter your name: ");

string name = Console.ReadLine();

القيمة التي يتم إرجاعها من Console.ReadLine() تكون نصًا، لذلك يمكن تخزينها في string.

Integer Input 
Console.Write("Enter your age: ");

int age = Convert.ToInt32(Console.ReadLine());

Console.WriteLine(age);

لأن Console.ReadLine() تقرأ النص، نستخدم Convert.ToInt32() لتحويل الإدخال إلى رقم صحيح.

Boolean Input 
Console.Write("Are you a student? ");

bool isStudent = Convert.ToBoolean(Console.ReadLine());

Console.WriteLine(isStudent);

يمكن استخدام Convert.ToBoolean() لتحويل الإدخال إلى قيمة منطقية true أو false.

Char Input 
Console.Write("Enter your grade: ");

char grade = Convert.ToChar(Console.ReadLine());

Console.WriteLine(grade);

يمكن استخدام Convert.ToChar() لتحويل الإدخال إلى حرف واحد.

Input and Output 
Console.Write("Enter your name: ");

string name = Console.ReadLine();

Console.WriteLine("Hello " + name);

يمكن استخدام الـ Input مع الـ Output لإنشاء برنامج يتفاعل مع المستخدم.

Important Notes
Console.ReadLine() تستخدم لقراءة الإدخال من المستخدم.
Convert.ToInt32() تحول الإدخال إلى عدد صحيح.
Convert.ToBoolean() تحول الإدخال إلى true أو false.
Convert.ToChar() تحول الإدخال إلى حرف.
