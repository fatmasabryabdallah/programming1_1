Computer Term

CPU

Central Processing Unit

Definition

CPU ما هي الـ

CPU هي اختصار لـ Central Processing Unit، وهي وحدة المعالجة التي تنفذ تعليمات البرامج وتعالج البيانات داخل الكمبيوتر.

Result
Explanation

عندما يقوم البرنامج بتنفيذ عملية، تحتاج التعليمات إلى المعالجة، وهنا يأتي دور الـ CPU.

تقوم وحدة المعالجة بتنفيذ التعليمات وإجراء العمليات الحسابية والمنطقية المطلوبة.

Main CPU Components
ALU تنفيذ العمليات الحسابية والمنطقية
Control Unit تنظيم وتنفيذ التعليمات
Registers تخزين قيم وتعليمات مؤقتة بسرعة عالية
Cache ذاكرة سريعة تساعد على الوصول إلى البيانات والتعليمات
CPU Tasks
Fetch جلب التعليمات
Decode فهم التعليمات وتفسيرها
Execute تنفيذ التعليمات
Store حفظ النتائج أو تمريرها للخطوة التالية
CPU vs RAM
CPU ينفذ التعليمات ويعالج البيانات
RAM تخزن مؤقتًا البيانات والتعليمات التي تحتاجها البرامج أثناء التشغيل
Why Is CPU Important?

الـCPU عنصر أساسي في تشغيل البرامج وتنفيذ التعليمات، ولذلك يؤثر أداؤه في قدرة النظام على معالجة المهام المختلفة.
