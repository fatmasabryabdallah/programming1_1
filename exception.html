Exception

الـ Exception هي مشكلة تحدث أثناء تشغيل البرنامج ويمكن التعامل معها باستخدام try و except.

Definition

الـ Exception هي حالة غير متوقعة تحدث أثناء تنفيذ البرنامج، مثل محاولة القسمة على صفر أو إدخال بيانات غير مناسبة.

يمكن التعامل مع هذه الأخطاء حتى لا يتوقف البرنامج بشكل مفاجئ.

Example 
number = 10
result = number / 0

print(result)

في هذا المثال تحدث مشكلة لأن القسمة على 0 غير صحيحة، وبالتالي يظهر Exception.

Try / Except

نستخدم try لوضع الكود الذي نتوقع أن يحدث فيه خطأ.

ونستخدم except للتعامل مع الخطأ إذا حدث. 

try:
    number = 10
    result = number / 0
    print(result)

except:
    print("An error occurred")
Specific Exception 
try:
    number = int("Hello")

except ValueError:
    print("Invalid value")

يمكن تحديد نوع الخطأ الذي نريد التعامل معه، مثل ValueError.

Finally 
try:
    print("Start")

except:
    print("Error")

finally:
    print("Finished")

يتم تنفيذ finally سواء حدث Exception أم لم يحدث.

Important Notes
try يحتوي على الكود الذي قد يحدث فيه خطأ.
except يستخدم للتعامل مع الـ Exception.
finally يتم تنفيذه في جميع الحالات.
ValueError يحدث عندما تكون القيمة غير مناسبة للعملية المطلوبة.
Practical Example 
try:
    age = int(input("Enter your age: "))
    print(age)

except ValueError:
    print("Please enter a valid number")

هنا إذا أدخل المستخدم رقمًا صحيحًا يتم تنفيذ البرنامج بشكل طبيعي، وإذا أدخل قيمة غير رقمية يتم التعامل مع الخطأ بدلًا من توقف البرنامج.
