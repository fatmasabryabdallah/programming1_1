Array

الـ Array تستخدم لتخزين مجموعة من القيم من نفس نوع البيانات داخل متغير واحد.

Definition

الـ Array هي مجموعة من العناصر من نفس نوع البيانات يتم تخزينها داخل متغير واحد.

يمكن الوصول إلى كل عنصر داخل الـ Array باستخدام Index.

Create an Array 
int[] numbers = { 10, 20, 30, 40, 50 };

Console.WriteLine(numbers[0]);

أنشأنا Array باسم numbers تحتوي على خمسة أرقام.

Index

يبدأ الـ Index في C# من الرقم 0. 

int[] numbers = { 10, 20, 30 };

Console.WriteLine(numbers[0]);
Console.WriteLine(numbers[1]);
Console.WriteLine(numbers[2]);

لذلك: numbers[0] تساوي 10، وnumbers[1] تساوي 20، وnumbers[2] تساوي 30.

String Array 
string[] names = {
    "Ali",
    "Ahmed",
    "Omar"
};

Console.WriteLine(names[0]);

يمكن إنشاء Array من نوع string لتخزين مجموعة من النصوص.

Change Value 
int[] numbers = { 10, 20, 30 };

numbers[1] = 50;

Console.WriteLine(numbers[1]);

يمكن تغيير قيمة عنصر داخل الـ Array باستخدام الـ Index الخاص به.

Length 
int[] numbers = { 10, 20, 30, 40, 50 };

Console.WriteLine(numbers.Length);

الخاصية Length تستخدم لمعرفة عدد العناصر الموجودة داخل الـ Array.

Loop with Array 
int[] numbers = { 10, 20, 30, 40, 50 };

for (int i = 0; i < numbers.Length; i++)
{
    Console.WriteLine(numbers[i]);
}

يمكن استخدام الـ for loop للمرور على جميع العناصر الموجودة داخل الـ Array.

Important Notes
Array تخزن مجموعة من القيم من نفس النوع.
Index يبدأ من 0.
Length تعطي عدد العناصر الموجودة في الـ Array.
int[] تستخدم لإنشاء Array من الأعداد الصحيحة.
