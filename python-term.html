Programming Language

Python

لغة برمجة متعددة الاستخدامات

Definition

Python ما هي

Python هي لغة برمجة عالية المستوى تتميز ببساطة بناء الجمل البرمجية وسهولة القراءة، وتُستخدم في مجالات متعددة من تطوير البرمجيات.

Example 
name = "Ammar"

print(name)
Explanation

في المثال السابق أنشأنا متغيرًا باسم name ووضعنا فيه نصًا.

ثم استخدمنا print() لعرض القيمة على الشاشة.

Python Uses
Web Development تطوير تطبيقات ومواقع الويب
Data Science تحليل البيانات ومعالجتها
Artificial Intelligence بناء تطبيقات الذكاء الاصطناعي والتعلم الآلي
Automation أتمتة المهام والعمليات المتكررة
Basic Python 
name = "Ammar"
age = 16

print(name)
print(age)
Python Features
Readable جمل برمجية سهلة القراءة نسبيًا
High Level لغة عالية المستوى
Versatile تستخدم في مجالات متعددة
Large Ecosystem توفر مكتبات وأدوات كثيرة لمجالات مختلفة
Why Learn Python?

Python مناسبة للمبتدئين نسبيًا، كما أنها تُستخدم في مجالات تقنية متعددة، لذلك يمكن أن تكون بداية جيدة لفهم أساسيات البرمجة وتطبيقها.
