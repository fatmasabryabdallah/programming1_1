Output

الـ Output يستخدم لعرض البيانات والنتائج على شاشة الـ Console.

Definition

الـ Output هو عرض البيانات أو الرسائل التي ينتجها البرنامج للمستخدم.

في C# نستخدم بشكل أساسي Console.Write() و Console.WriteLine() لعرض البيانات في الـ Console.

Console.WriteLine() 
Console.WriteLine("Hello World");

تستخدم Console.WriteLine() لطباعة البيانات ثم الانتقال إلى سطر جديد.

Console.Write() 
Console.Write("Hello ");
Console.Write("World");

تستخدم Console.Write() لطباعة البيانات دون الانتقال إلى سطر جديد.

Write vs WriteLine
Console.Write() تطبع البيانات وتبقى في نفس السطر.
Console.WriteLine() تطبع البيانات ثم تنتقل إلى سطر جديد.
Output with Variable 
string name = "Ammar";
int age = 16;

Console.WriteLine(name);
Console.WriteLine(age);

يمكن استخدام الـ Output لعرض القيم المخزنة داخل المتغيرات.

Multiple Output 
Console.WriteLine("Name: Ammar");
Console.WriteLine("Age: 16");
Console.WriteLine("Student: True");

يمكن استخدام أكثر من أمر طباعة لعرض عدة بيانات للمستخدم.

Concatenation 
string name = "Ammar";
int age = 16;

Console.WriteLine("Name: " + name);
Console.WriteLine("Age: " + age);

يمكن دمج النصوص مع قيم المتغيرات باستخدام علامة +.

Important Notes
Write() تطبع في نفس السطر.
WriteLine() تطبع ثم تنتقل إلى سطر جديد.
Console تستخدم للتعامل مع شاشة الـ Console.
+ يمكن استخدامه لدمج النصوص مع القيم.
