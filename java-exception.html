Exception

الـ Exception هي مشكلة تحدث أثناء تشغيل البرنامج ويمكن التعامل معها باستخدام try و catch.

Definition

الـ Exception هي حالة غير متوقعة تحدث أثناء تنفيذ البرنامج وقد تمنع البرنامج من الاستمرار بشكل طبيعي.

يمكن التعامل مع هذه الحالات باستخدام try و catch بدلًا من توقف البرنامج بشكل مفاجئ.

Example 
int number = 10;

System.out.println(number / 0);

في هذا المثال نحاول القسمة على صفر، وهذا يؤدي إلى حدوث ArithmeticException.

Try / Catch

نستخدم try لوضع الكود الذي قد يحدث فيه خطأ، ونستخدم catch للتعامل مع الخطأ إذا حدث. 

try {

    int number = 10;
    int result = number / 0;

    System.out.println(result);

} catch (ArithmeticException e) {

    System.out.println("Cannot divide by zero");

}

إذا حدث الخطأ داخل try يتم تنفيذ الكود الموجود داخل catch.

Specific Exception 
try {

    int number = Integer.parseInt("Hello");

} catch (NumberFormatException e) {

    System.out.println("Invalid number");

}

يمكن تحديد نوع معين من الـ Exception، مثل NumberFormatException عندما لا يمكن تحويل النص إلى رقم.

Finally 
try {

    System.out.println("Start");

} catch (Exception e) {

    System.out.println("Error");

} finally {

    System.out.println("Finished");

}

يتم تنفيذ finally سواء حدث Exception أم لم يحدث.

Common Exceptions
ArithmeticException تحدث عند حدوث خطأ في عملية حسابية مثل القسمة على صفر.
NumberFormatException تحدث عند محاولة تحويل قيمة غير مناسبة إلى رقم.
ArrayIndexOutOfBoundsException تحدث عند الوصول إلى Index غير موجود داخل Array.
Exception نوع عام يمكن استخدامه للتعامل مع الاستثناءات.
Practical Example 
import java.util.Scanner;

Scanner input = new Scanner(System.in);

try {

    System.out.print("Enter a number: ");

    int number = input.nextInt();

    System.out.println(number);

} catch (Exception e) {

    System.out.println("Please enter a valid number");

}

هنا إذا أدخل المستخدم رقمًا صحيحًا يعمل البرنامج بشكل طبيعي، وإذا أدخل قيمة غير مناسبة يتم التعامل مع الخطأ باستخدام catch.

Important Notes
try تحتوي على الكود الذي قد يحدث فيه خطأ.
catch تستخدم للتعامل مع الـ Exception.
finally يتم تنفيذها سواء حدث خطأ أم لا.
Exception تمثل مشكلة تحدث أثناء تنفيذ البرنامج.
