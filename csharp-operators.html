Operators

الـ Operators هي رموز تستخدم لإجراء العمليات الحسابية والمقارنة والمنطقية في C#.

Definition

الـ Operators تستخدم لتنفيذ عمليات مختلفة على القيم والمتغيرات.

مثل الجمع والطرح والمقارنة ومعرفة العلاقة بين القيم واستخدام الشروط المنطقية.

Arithmetic Operators 
int a = 10;
int b = 3;

Console.WriteLine(a + b);
Console.WriteLine(a - b);
Console.WriteLine(a * b);
Console.WriteLine(a / b);
Console.WriteLine(a % b);

تستخدم هذه العمليات لتنفيذ العمليات الحسابية مثل الجمع والطرح والضرب والقسمة وباقي القسمة.

Arithmetic Operators
+ الجمع.
- الطرح.
* الضرب.
/ القسمة.
% باقي القسمة.
Assignment Operators 
int number = 10;

number += 5;

Console.WriteLine(number);

تستخدم Assignment Operators لإعطاء قيمة للمتغير أو تعديل قيمته بطريقة مختصرة.

Comparison Operators
== يساوي.
!= لا يساوي.
> أكبر من.
< أصغر من.
>= أكبر من أو يساوي.
<= أصغر من أو يساوي.
Comparison Example 
int age = 18;

Console.WriteLine(age >= 18);

نتيجة المقارنة تكون قيمة منطقية true أو false.

Logical Operators
&& AND: يجب أن يكون الشرطان صحيحين.
|| OR: يكفي أن يكون أحد الشرطين صحيحًا.
! NOT: تعكس القيمة المنطقية.
Logical Example 
int age = 20;
bool hasId = true;

Console.WriteLine(age >= 18 && hasId);

هنا يجب أن يكون العمر 18 أو أكثر وأن تكون قيمة hasId تساوي true حتى تكون النتيجة true.

Important Notes
Arithmetic تستخدم للعمليات الحسابية.
Assignment تستخدم لإعطاء أو تعديل قيمة المتغير.
Comparison تستخدم لمقارنة القيم.
Logical تستخدم لربط الشروط المنطقية.
