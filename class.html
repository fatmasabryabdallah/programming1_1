HTML Term

Class

الفئة أو التصنيف

Definition

Class ما هو الـ

اسماً خاصاً عن باقي الأسماء ويكون له تنسيق خاص Html هو خاصيه تستخدم لإعطاء عنصر، Class الـ

Example 
<p class="title">
    Hello World
</p>
Explanation

class في المثال السابق هو اسم الـ title.

CSS ويمكن استخدام الاسم نفسه مع أكثر من عنصر، ثم تنسيقه باستخدام .

Class Example
.title تنسيق العناوين
.card تنسيق الكروت
.button تنسيق الأزرار
.container تنسيق الحاوية
