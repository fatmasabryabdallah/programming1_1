Programming Term

Operator

عامل التشغيل

Definition

Operator ما هو الـ

الـ Operator هو رمز أو كلمة تستخدم لإجراء عملية معينة على القيم أو البيانات داخل البرنامج.

Example 
let a = 10;
let b = 5;

let result = a + b;
Explanation

في المثال السابق، الرمز + هو Operator يستخدم لجمع الرقمين.

ويوجد العديد من أنواع الـOperators، وكل نوع له وظيفة مختلفة.

Arithmetic Operators
+ الجمع
- الطرح
* الضرب
/ القسمة
% باقي القسمة
** الأس
Comparison Operators
== مقارنة القيم في بعض اللغات
=== مقارنة القيمة والنوع في JavaScript
!= لا يساوي في بعض اللغات
> أكبر من
< أصغر من
>= أكبر من أو يساوي
Assignment Operators
= إسناد قيمة
+= إضافة قيمة ثم إسنادها
-= طرح قيمة ثم إسنادها
*= ضرب القيمة ثم إسنادها
Example in C# 
int a = 10;
int b = 5;

int result = a + b;

Console.WriteLine(result);
Example in JavaScript 
let a = 10;
let b = 5;

let result = a + b;

console.log(result);
