Computer Term

Data

البيانات

Definition

Data ما هي الـ

الـ Data هي حقائق أو قيم خام يمكن جمعها وتخزينها ومعالجتها باستخدام الكمبيوتر.

Examples 
Name = "Ammar"
Age = 16
Grade = 90
Explanation

القيم السابقة تمثل بيانات خام يمكن للبرنامج تخزينها أو معالجتها أو استخدامها في عمليات مختلفة.

بعد معالجة البيانات وتنظيمها بطريقة مفيدة، يمكن أن تتحول إلى Information.

Types of Data
Text بيانات نصية مثل الأسماء والكلمات
Numbers بيانات رقمية مثل الأعمار والدرجات
Images بيانات على شكل صور
Audio بيانات صوتية
Video بيانات مرئية متحركة
Boolean بيانات منطقية مثل true و false
Data in Programming 
int age = 16;
string name = "Ammar";
bool isStudent = true;
Data Processing 
Raw Data
    ↓
Processing
    ↓
Useful Result
    ↓
Information
Data vs Information
Data حقائق أو قيم خام تحتاج إلى معالجة
Information بيانات تمت معالجتها وأصبحت ذات معنى
Why Is Data Important?

البيانات هي أساس كثير من العمليات الحاسوبية، فالبرامج تستخدمها في التخزين والمعالجة واتخاذ القرارات وإنتاج النتائج.
