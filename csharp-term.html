C#

C# هي لغة برمجة حديثة طورتها Microsoft وتستخدم في إنشاء أنواع مختلفة من التطبيقات.

Definition

C# هي لغة برمجة قوية ومتعددة الاستخدامات، تم تطويرها بواسطة Microsoft وتعمل ضمن منصة .NET.

تستخدم في تطوير تطبيقات سطح المكتب، وتطبيقات الويب، والألعاب، والعديد من أنواع البرامج.

Example 
Console.WriteLine("Hello World");

هذا المثال يستخدم Console.WriteLine() لطباعة النص على شاشة الـ Console.

Features

من أهم مميزات C# أنها لغة منظمة وتدعم Object-Oriented Programming وتوفر أدوات كثيرة لبناء التطبيقات.

كما أنها تتكامل بشكل كبير مع منصة .NET.

Uses
Desktop Apps تستخدم في إنشاء تطبيقات سطح المكتب.
Web Apps تستخدم في تطوير تطبيقات ومواقع الويب.
Game Development تستخدم في تطوير الألعاب، خاصة مع Unity.
.NET تعمل بشكل أساسي ضمن منصة .NET.
Variable Example 
int age = 16;
string name = "Ammar";

Console.WriteLine(name);
Console.WriteLine(age);

في C# يمكن تخزين البيانات داخل Variables وتحديد نوع البيانات عند إنشاء المتغير.

Important Notes
C# لغة برمجة من تطوير Microsoft.
.NET منصة تستخدم لتطوير وتشغيل تطبيقات C#.
Console.WriteLine() تستخدم لطباعة البيانات في الـ Console.
Case-Sensitive C# تفرق بين الأحرف الكبيرة والصغيرة.
