Python Term

Variable

المتغير في Python

Definition

Variable ما هو الـ

الـ Variable هو اسم نستخدمه للإشارة إلى قيمة مخزنة في البرنامج، ويمكن إعادة إسناد قيمة جديدة إليه أثناء تنفيذ البرنامج.

Example 
name = "Ammar"
age = 16

print(name)
print(age)
Explanation

في Python لا نحتاج عادةً إلى كتابة نوع البيانات عند إنشاء المتغير.

البرنامج يحدد نوع القيمة من البيانات التي نضعها في المتغير.

Variable Examples
name = "Ammar" متغير يحتوي على نص
age = 16 متغير يحتوي على رقم صحيح
price = 19.5 متغير يحتوي على رقم عشري
is_student = True متغير يحتوي على قيمة منطقية
Changing a Variable 
age = 16

age = 17

print(age)
Multiple Variables 
name = "Ammar"
age = 16
city = "Gharbia"
Important Rules
name يمكن أن يحتوي على أحرف وأرقام وشرطة سفلية
_name يمكن أن يبدأ بشرطة سفلية
2name اسم غير صحيح لأنه يبدأ برقم
user_name مثال شائع لاسم واضح للمتغير
Check the Type 
age = 16

print(type(age))
Why Are Variables Important?

المتغيرات تسمح للبرنامج بتخزين البيانات واستخدامها وتغييرها أثناء تنفيذ العمليات المختلفة.
