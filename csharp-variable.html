Variable

الـ Variable هو مكان في الذاكرة يستخدم لتخزين قيمة يمكن استخدامها وتغييرها أثناء تشغيل البرنامج.

Definition

الـ Variable هو متغير نستخدمه لتخزين بيانات مثل الأرقام أو النصوص أو القيم المنطقية داخل البرنامج.

في C# يجب تحديد Data Type للمتغير قبل كتابة القيمة التي سيتم تخزينها.

Example 
int age = 16;
string name = "Ammar";

في المثال السابق أنشأنا متغيرًا باسم age لتخزين رقم صحيح، ومتغيرًا باسم name لتخزين نص.

Syntax

الشكل الأساسي لإنشاء Variable في C# هو: 

DataType variableName = value;

نكتب أولًا نوع البيانات، ثم اسم المتغير، ثم نضع القيمة بعد علامة =.

Variable Types
int لتخزين الأعداد الصحيحة.
float لتخزين الأعداد العشرية.
string لتخزين النصوص.
bool لتخزين True أو False.
Change Value 
int age = 16;

age = 17;

Console.WriteLine(age);

يمكن تغيير قيمة المتغير بعد إنشائه، مع الحفاظ على نوع البيانات المناسب.

Using Variable 
string name = "Ammar";

Console.WriteLine(name);

يمكن استخدام اسم المتغير للوصول إلى القيمة المخزنة بداخله، مثل طباعتها باستخدام Console.WriteLine().

Important Notes
Variable Name الاسم الذي نستخدمه للوصول إلى المتغير.
Data Type يحدد نوع البيانات التي يمكن تخزينها.
= تستخدم لإعطاء قيمة للمتغير.
; تستخدم لإنهاء الجملة البرمجية.
Multiple Variables 
string name = "Ammar";
int age = 16;
bool isStudent = true;

Console.WriteLine(name);
Console.WriteLine(age);
Console.WriteLine(isStudent);

يمكن إنشاء أكثر من Variable داخل نفس البرنامج، ولكل متغير اسم ونوع وقيمة خاصة به.
