Function

الـ Function هي مجموعة من الأوامر البرمجية يتم تجميعها لتنفيذ مهمة معينة ويمكن استدعاؤها عند الحاجة.

Definition

الـ Function في C# هي جزء من البرنامج يحتوي على مجموعة من الأوامر البرمجية التي تنفذ مهمة محددة.

استخدام Functions يساعد على تنظيم الكود وإعادة استخدامه بدلًا من كتابة نفس الأوامر أكثر من مرة.

Basic Function 
static void SayHello()
{
    Console.WriteLine("Hello World");
}

SayHello();

في المثال السابق أنشأنا Function باسم SayHello، ثم استدعيناها باستخدام SayHello().

Explanation

كلمة void تعني أن الـ Function لا ترجع قيمة.

اسم الـ Function يمكن اختياره حسب المهمة التي تنفذها، مثل SayHello.

الكود الموجود بين الأقواس { } هو الكود الذي سيتم تنفيذه عند استدعاء الـ Function.

Parameters 
static void Greet(string name)
{
    Console.WriteLine("Hello " + name);
}

Greet("Ammar");

يمكن للـ Function استقبال بيانات تسمى Parameters، ثم استخدامها داخل الـ Function.

Multiple Parameters 
static void ShowInfo(string name, int age)
{
    Console.WriteLine(name);
    Console.WriteLine(age);
}

ShowInfo("Ammar", 16);

يمكن للـ Function استقبال أكثر من Parameter، وكل Parameter يمكن أن يكون له Data Type مختلف.

Return Value 
static int Add(int a, int b)
{
    return a + b;
}

int result = Add(5, 3);

Console.WriteLine(result);

يمكن للـ Function إرجاع قيمة باستخدام return. وفي المثال السابق تقوم Function بإرجاع ناتج الجمع.

Return Types
void Function لا ترجع قيمة.
int Function ترجع عددًا صحيحًا.
string Function ترجع نصًا.
bool Function ترجع true أو false.
Important Notes
Function مجموعة أوامر لتنفيذ مهمة محددة.
Parameter قيمة يتم استقبالها داخل الـ Function.
return تستخدم لإرجاع قيمة من الـ Function.
void تعني أن الـ Function لا ترجع قيمة.
