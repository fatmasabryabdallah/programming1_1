Exception

الـ Exception هي مشكلة تحدث أثناء تشغيل البرنامج ويمكن التعامل معها باستخدام try و catch.

Definition

الـ Exception هو خطأ يحدث أثناء تشغيل البرنامج وقد يمنع البرنامج من إكمال التنفيذ بشكل طبيعي.

يمكن التعامل مع هذه الأخطاء باستخدام try و catch بدلًا من توقف البرنامج بشكل مفاجئ.

Example 
int number = 10;

Console.WriteLine(number / 0);

في هذا المثال نحاول القسمة على صفر، وهذا يؤدي إلى حدوث Exception.

Try / Catch

نستخدم try لوضع الكود الذي قد يحدث فيه خطأ، ونستخدم catch للتعامل مع الخطأ إذا حدث. 

try
{
    int number = 10;
    int result = number / 0;

    Console.WriteLine(result);
}
catch
{
    Console.WriteLine("An error occurred");
}

إذا حدث خطأ داخل try يتم تنفيذ الكود الموجود داخل catch.

Specific Exception 
try
{
    int number = int.Parse("Hello");
}
catch (FormatException)
{
    Console.WriteLine("Invalid format");
}

يمكن تحديد نوع معين من الأخطاء، مثل FormatException عندما تكون صيغة البيانات غير صحيحة.

Finally 
try
{
    Console.WriteLine("Start");
}
catch
{
    Console.WriteLine("Error");
}
finally
{
    Console.WriteLine("Finished");
}

يتم تنفيذ finally سواء حدث Exception أم لم يحدث.

Common Exceptions
DivideByZeroException تحدث عند محاولة القسمة على صفر.
FormatException تحدث عندما تكون صيغة البيانات غير صحيحة.
IndexOutOfRangeException تحدث عند محاولة الوصول إلى Index غير موجود.
Exception نوع عام يمكن استخدامه للتعامل مع الأخطاء.
Practical Example 
try
{
    Console.Write("Enter a number: ");

    int number = Convert.ToInt32(
        Console.ReadLine()
    );

    Console.WriteLine(number);
}
catch (FormatException)
{
    Console.WriteLine("Please enter a valid number");
}

هنا إذا أدخل المستخدم رقمًا صحيحًا يعمل البرنامج بشكل طبيعي، وإذا أدخل قيمة غير رقمية يتم التعامل مع الخطأ باستخدام catch.

Important Notes
try تحتوي على الكود الذي قد يحدث فيه خطأ.
catch تستخدم للتعامل مع الـ Exception.
finally يتم تنفيذها سواء حدث خطأ أم لا.
Exception تمثل مشكلة تحدث أثناء تنفيذ البرنامج.
