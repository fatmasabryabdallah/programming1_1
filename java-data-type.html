Data Type

الـ Data Type يحدد نوع البيانات التي يمكن تخزينها داخل المتغير.

Definition

الـ Data Type هو النوع الذي يحدد طبيعة القيمة التي يمكن تخزينها داخل المتغير في Java.

من أهم أنواع البيانات الأساسية في Java: int، double، char، boolean، وString.

int 
int age = 16;

System.out.println(age);

int يستخدم لتخزين الأعداد الصحيحة مثل 10 و 25 و 100.

double 
double price = 99.99;

System.out.println(price);

double يستخدم لتخزين الأعداد العشرية مثل 10.5 و 99.99.

char 
char grade = 'A';

System.out.println(grade);

char يستخدم لتخزين حرف واحد فقط، ويكتب الحرف بين علامات الاقتباس المفردة.

boolean 
boolean isStudent = true;

System.out.println(isStudent);

boolean يستخدم لتخزين قيمة منطقية تكون إما true أو false.

String 
String name = "Ammar";

System.out.println(name);

String يستخدم لتخزين النصوص، مثل الأسماء والجمل والكلمات.

Common Data Types
int لتخزين الأعداد الصحيحة.
double لتخزين الأعداد العشرية.
char لتخزين حرف واحد.
boolean لتخزين true أو false.
String لتخزين النصوص.
Multiple Data Types 
String name = "Ammar";
int age = 16;
double height = 1.75;
char grade = 'A';
boolean isStudent = true;

System.out.println(name);
System.out.println(age);
System.out.println(height);
System.out.println(grade);
System.out.println(isStudent);

يمكن استخدام أنواع مختلفة من البيانات داخل نفس البرنامج حسب نوع المعلومات التي نحتاج إلى تخزينها.

Important Notes
int أعداد صحيحة.
double أعداد عشرية.
String نصوص.
char حرف واحد.
boolean true أو false.
