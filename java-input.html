Input

الـ Input يستخدم لاستقبال البيانات من المستخدم أثناء تشغيل البرنامج.

Definition

الـ Input هو البيانات التي يدخلها المستخدم إلى البرنامج أثناء تشغيله.

في Java يمكن استخدام Scanner لقراءة البيانات من لوحة المفاتيح.

Scanner 
import java.util.Scanner;

Scanner input = new Scanner(System.in);

System.out.print("Enter your name: ");

String name = input.nextLine();

System.out.println(name);

نستخدم Scanner لقراءة البيانات التي يكتبها المستخدم من لوحة المفاتيح.

String Input 
Scanner input = new Scanner(System.in);

System.out.print("Enter your name: ");

String name = input.nextLine();

تستخدم nextLine() لقراءة سطر كامل من النص.

Integer Input 
Scanner input = new Scanner(System.in);

System.out.print("Enter your age: ");

int age = input.nextInt();

System.out.println(age);

تستخدم nextInt() لقراءة عدد صحيح من المستخدم.

Double Input 
Scanner input = new Scanner(System.in);

System.out.print("Enter price: ");

double price = input.nextDouble();

System.out.println(price);

تستخدم nextDouble() لقراءة عدد عشري.

Boolean Input 
Scanner input = new Scanner(System.in);

System.out.print("Are you a student? ");

boolean isStudent = input.nextBoolean();

System.out.println(isStudent);

تستخدم nextBoolean() لقراءة قيمة منطقية مثل true أو false.

Char Input 
Scanner input = new Scanner(System.in);

System.out.print("Enter your grade: ");

char grade = input.next().charAt(0);

System.out.println(grade);

يمكن قراءة حرف واحد باستخدام next() ثم charAt(0).

Input and Output 
Scanner input = new Scanner(System.in);

System.out.print("Enter your name: ");

String name = input.nextLine();

System.out.println("Hello " + name);

يمكن استخدام الـ Input مع الـ Output لإنشاء برنامج يتفاعل مع المستخدم.

Important Notes
Scanner تستخدم لقراءة البيانات من المستخدم.
nextLine() تقرأ سطرًا كاملًا من النص.
nextInt() تقرأ عددًا صحيحًا.
nextDouble() تقرأ عددًا عشريًا.
nextBoolean() تقرأ قيمة true أو false.
