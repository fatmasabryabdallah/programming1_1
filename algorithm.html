Programming Term

Algorithm

الخوارزمية

Definition

Algorithm ما هي الـ

الـ Algorithm هي مجموعة من الخطوات المرتبة والمنطقية التي نستخدمها لحل مشكلة معينة أو تنفيذ مهمة محددة.

Example 
1. Start
2. Enter two numbers
3. Add the numbers
4. Display the result
5. End
Explanation

لنفترض أننا نريد إنشاء برنامج يقوم بجمع رقمين. قبل كتابة الكود، نحدد خطوات الحل بالترتيب.

نبدأ بإدخال الرقمين، ثم نجمعهما، وبعد ذلك نعرض النتيجة للمستخدم.

Algorithm Characteristics
Step by Step الخطوات تكون مرتبة وواضحة
Input يمكن أن تستقبل بيانات
Process تنفذ مجموعة من العمليات
Output تنتج نتيجة أو حلًا
Simple Example 
Start
  ↓
Enter Number
  ↓
Multiply by 2
  ↓
Display Result
  ↓
End
Why Is It Important?

الخوارزميات تساعد المبرمج على التفكير في المشكلة وتقسيمها إلى خطوات واضحة قبل تحويل الحل إلى كود.
