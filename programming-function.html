Programming Term

Function

الدالة

Definition

Function ما هي الـ

الـ Function هي مجموعة من التعليمات البرمجية يتم تجميعها لتنفيذ مهمة محددة، ويمكن استدعاؤها عند الحاجة بدلًا من كتابة نفس التعليمات مرة أخرى.

General Structure 
Function Name
    ↓
Receive Data
    ↓
Process
    ↓
Return Result
Explanation

بدلًا من كتابة مجموعة من التعليمات في أكثر من مكان، يمكن وضعها داخل Function ثم استدعاؤها وقت الحاجة.

بعض الدوال تستقبل بيانات تسمى Parameters وبعضها يمكن أن يعيد نتيجة تسمى Return Value.

Function Parts
Name اسم الدالة
Parameters البيانات التي تستقبلها الدالة
Body التعليمات الموجودة داخل الدالة
Return النتيجة التي يمكن أن تعيدها الدالة
Example in C# 
int Add(int a, int b)
{
    return a + b;
}
Example in JavaScript 
function add(a, b) {
    return a + b;
}
Function Without Parameters 
function sayHello() {
    console.log("Hello");
}

sayHello();
Why Are Functions Important?

الدوال تساعد على تنظيم البرنامج وتقليل تكرار الكود، كما تجعل تقسيم المشكلات الكبيرة إلى مهام صغيرة أسهل.
