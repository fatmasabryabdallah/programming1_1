HTML Term

Attribute

HTML الخاصية في

Definition

Attribute ما هو الـ

لتوفير معلومات إضافية عنه أو لتحديد سلوكه. HTML هو خاصية تُضاف إلى عنصر Attribute الـ

Example 
<a href="https://example.com">
Visit Website
</a>
Explanation

<a>. للعنصر Attribute هي href في المثال السابق، الخاصية

وهي تحدد الرابط الذي سينتقل إليه المستخدم عند الضغط على العنصر.

Common Attributes
id معرّف فريد للعنصر
class تحديد مجموعة أو تصنيف للعنصر
href تحديد رابط
src تحديد مصدر الملف
