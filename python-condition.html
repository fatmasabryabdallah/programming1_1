Condition

الـ Condition تستخدم لاتخاذ قرار معين بناءً على تحقق شرط من عدمه.

Definition

الـ Condition هي عبارة شرطية تستخدم لجعل البرنامج يتصرف بطريقة مختلفة حسب نتيجة الشرط.

في Python نستخدم بشكل أساسي if و elif و else.

If Statement 
age = 18

if age >= 18:
    print("Adult")

إذا كان الشرط age >= 18 صحيحًا، فسيتم تنفيذ أمر الطباعة.

Explanation

نستخدم if لاختبار الشرط.

إذا كانت نتيجة الشرط True يتم تنفيذ الكود الموجود داخل الـ if.

أما إذا كانت النتيجة False فلن يتم تنفيذ هذا الجزء.

If / Else 
age = 16

if age >= 18:
    print("Adult")
else:
    print("Not Adult")

هنا إذا كان الشرط صحيحًا يتم تنفيذ جزء if، وإذا كان غير صحيح يتم تنفيذ جزء else.

Elif 
grade = 85

if grade >= 90:
    print("Excellent")
elif grade >= 75:
    print("Very Good")
else:
    print("Good")

نستخدم elif عندما نريد اختبار شرط إضافي بعد الشرط الأول.

Comparison Operators
== للمقارنة بين قيمتين ومعرفة هل هما متساويتان.
!= للتأكد من أن القيمتين غير متساويتين.
> أكبر من.
< أصغر من.
>= أكبر من أو يساوي.
<= أصغر من أو يساوي.
Multiple Conditions 
age = 20
has_id = True

if age >= 18 and has_id:
    print("Access Granted")
else:
    print("Access Denied")

يمكن استخدام أكثر من شرط معًا باستخدام and و or للحصول على قرارات أكثر دقة.

Important Notes
if تستخدم لاختبار الشرط الأساسي.
elif تستخدم لاختبار شرط إضافي.
else تعمل عندما تكون الشروط السابقة False.
Indentation المسافة البادئة تحدد الكود الموجود داخل الشرط.
