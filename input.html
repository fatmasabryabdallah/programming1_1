Programming Term

Input

المدخلات

Definition

Input ما هو الـ

الـ Input هو البيانات أو المعلومات التي يتم إدخالها إلى البرنامج حتى يستطيع التعامل معها وتنفيذ العمليات المطلوبة.

General Example 
User enters:
Name = "Ammar"
Age = 16
Explanation

في المثال السابق، قام المستخدم بإدخال اسمه وعمره إلى البرنامج.

هذه البيانات تعتبر Input لأنها دخلت إلى البرنامج ليتم استخدامها لاحقًا.

Types of Input
Keyboard إدخال البيانات باستخدام لوحة المفاتيح
Mouse إدخال من خلال النقر أو الاختيار
File قراءة البيانات من ملف
User Input البيانات التي يدخلها المستخدم
Example in C# 
Console.Write("Enter your name: ");

string name = Console.ReadLine();
Example in JavaScript 
let name = prompt("Enter your name");
