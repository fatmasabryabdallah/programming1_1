Function

الدالة هي مجموعة من الأوامر البرمجية يتم تعريفها مرة واحدة ويمكن استخدامها أكثر من مرة لتنفيذ مهمة معينة.

Definition

تستخدم Function في Python لتجميع مجموعة من الأوامر داخل جزء واحد من الكود، ويمكن استدعاء هذه الدالة عند الحاجة إليها.

Example 
def hello():
    print("Hello World")

hello()
Explanation

نستخدم الكلمة def لإنشاء دالة جديدة.

في المثال السابق أنشأنا دالة باسم hello وتحتوي على أمر طباعة.

عند كتابة hello() يتم استدعاء الدالة وتنفيذ الأوامر الموجودة بداخلها.

Common Python Function Terms
def تستخدم لإنشاء الدالة.
Function Name اسم الدالة التي نختارها.
() تستخدم لتمرير Parameters عند الحاجة.
return تستخدم لإرجاع قيمة من الدالة.
Another Example 
def add(a, b):
    return a + b

result = add(5, 3)

print(result)

هنا الدالة add تستقبل قيمتين ثم تقوم بجمعهما وإرجاع النتيجة باستخدام return.
