JavaScript Term

Condition

الشرط

Definition

Condition ما هي الـ

هي طريقة تجعل البرنامج يتخذ قرارًا بناءً على تحقق شرط معين.

Example 
let age = 18;

if (age >= 18) {
    console.log("Adult");
} else {
    console.log("Under 18");
}
Explanation

في المثال السابق، يتحقق البرنامج من قيمة age.

إذا كان العمر أكبر من أو يساوي 18. يتم تنفيذ الكود داخل if، وإلا يتم تنفيذ الكود داخل else.

Common Conditions
if تنفيذ الكود إذا كان الشرط صحيحًا
else تنفيذ كود بديل إذا كان الشرط غير صحيح
else if اختبار شرط إضافي
switch اختيار حالة من عدة حالات
Comparison Operators
=== يساوي في القيمة والنوع
!== لا يساوي في القيمة أو النوع
> أكبر من
< أصغر من
Another Example 
let number = 10;

if (number > 5) {
    console.log("Number is greater than 5");
}
