Programming Term

Output

المخرجات

Definition

Output ما هو الـ

الـ Output هو النتيجة أو البيانات التي ينتجها البرنامج بعد معالجة المدخلات وتنفيذ العمليات المطلوبة.

General Example 
Input:
10 + 5

Process:
Add the numbers

Output:
15
Explanation

في المثال السابق، أدخل المستخدم رقمين ثم قام البرنامج بجمعهما.

النتيجة 15 هي الـ Output لأنها المعلومة التي أنتجها البرنامج.

Types of Output
Text عرض النصوص والرسائل
Number عرض النتائج الرقمية
Image عرض الصور والمحتوى المرئي
File حفظ النتائج داخل ملف
Example in C# 
int result = 10 + 5;

Console.WriteLine(result);
Example in JavaScript 
let result = 10 + 5;

console.log(result);

Input
  ↓

  ↓

Why Is Output Important?

الـ Output هو الطريقة التي يعرض بها البرنامج النتيجة للمستخدم أو يرسلها إلى مكان آخر بعد معالجة البيانات.
