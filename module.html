Module

الـ Module هو ملف يحتوي على كود Python يمكن استخدامه داخل ملفات Python أخرى.

Definition

الـ Module هو ملف Python يحتوي على متغيرات أو Functions أو Classes ويمكن استيراده واستخدام محتواه في ملف آخر.

تساعد الـ Modules على تنظيم المشروع وتقسيم الكود إلى ملفات منفصلة.

Create a Module 
# math_tools.py

def add(a, b):
    return a + b

في المثال السابق أنشأنا ملفًا باسم math_tools.py يحتوي على Function اسمها add.

Import

لاستخدام Module داخل ملف آخر نستخدم كلمة import. 

import math_tools

result = math_tools.add(5, 3)

print(result)

هنا قمنا باستيراد math_tools ثم استخدمنا الـ Function الموجودة بداخله.

From Import 
from math_tools import add

result = add(10, 20)

print(result)

باستخدام from ... import يمكن استيراد Function محددة بدلًا من استيراد الـ Module بالكامل.

Built-in Module 
import math

print(math.sqrt(25))
print(math.pi)

Python تحتوي على Modules جاهزة يمكن استخدامها مباشرة مثل math التي توفر العديد من العمليات الرياضية.

Important Notes
Module ملف Python يحتوي على كود يمكن إعادة استخدامه.
import تستخدم لاستيراد Module.
from تستخدم لاستيراد جزء محدد من Module.
.py امتداد ملفات Python.
Why Use Modules?

استخدام الـ Modules يجعل المشروع أكثر تنظيمًا، ويساعد على إعادة استخدام الكود بدلًا من كتابته مرة أخرى في كل ملف.
