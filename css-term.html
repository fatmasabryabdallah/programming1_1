Programming Language

CSS

Cascading Style Sheets

Definition

CSS ما هي

هي لغة تُستخدم لتنسيق وتصميم صفحات الويب، مثل الألوان والخطوط والمسافات والأحجام وترتيب العناصر.

Example 
h1 {
    color: #d6b98c;
    font-size: 32px;
}
Explanation

ثم نضيف له خصائص . h1 في المثال السابق، نحدد عنصر

تحدد لون النص، color تحدد حجم الخط. والخاصية font-size الخاصية

What Can CSS Do?
Colors تغيير ألوان العناصر والنصوص
Fonts التحكم في الخطوط وأحجامها
Layout تنظيم وترتيب العناصر
Responsive جعل الموقع مناسبًا للشاشات المختلفة
CSS Structure 
selector {
    property: value;
}
