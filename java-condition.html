Condition

الـ Condition تستخدم لاتخاذ قرار معين بناءً على نتيجة الشرط.

Definition

الـ Condition هي عبارة شرطية تجعل البرنامج ينفذ أوامر مختلفة حسب نتيجة الشرط.

في Java نستخدم بشكل أساسي if و else if و else.

If Statement 
int age = 18;

if (age >= 18) {
    System.out.println("Adult");
}

إذا كان الشرط age >= 18 صحيحًا، يتم تنفيذ الكود الموجود داخل if.

If / Else 
int age = 16;

if (age >= 18) {
    System.out.println("Adult");
} else {
    System.out.println("Not Adult");
}

إذا كان الشرط صحيحًا يتم تنفيذ if، وإذا كان غير صحيح يتم تنفيذ else.

Else If 
int grade = 85;

if (grade >= 90) {
    System.out.println("Excellent");
} else if (grade >= 75) {
    System.out.println("Very Good");
} else {
    System.out.println("Good");
}

نستخدم else if لاختبار شرط إضافي بعد الشرط الأول.

Comparison Operators
== يساوي.
!= لا يساوي.
> أكبر من.
< أصغر من.
>= أكبر من أو يساوي.
<= أصغر من أو يساوي.
Multiple Conditions 
int age = 20;
boolean hasId = true;

if (age >= 18 && hasId) {
    System.out.println("Access Granted");
} else {
    System.out.println("Access Denied");
}

يمكن استخدام أكثر من شرط معًا باستخدام && و || للحصول على قرار أكثر دقة.

Logical Operators
&& AND: يجب أن يكون الشرطان صحيحين.
|| OR: يكفي أن يكون أحد الشرطين صحيحًا.
! NOT: تعكس القيمة المنطقية.
Practical Example 
int mark = 80;

if (mark >= 50) {
    System.out.println("Pass");
} else {
    System.out.println("Fail");
}

إذا كانت الدرجة 50 أو أكثر تكون النتيجة Pass، وإلا تكون Fail.

Important Notes
if لاختبار الشرط الأساسي.
else if لاختبار شرط إضافي.
else تعمل عندما تكون الشروط السابقة غير صحيحة.
Boolean Result نتيجة المقارنة تكون true أو false.
