Programming Term

Variable

المتغير

Definition

Variable ما هو الـ

الـ Variable هو اسم نستخدمه للوصول إلى قيمة مخزنة في البرنامج، ويمكن أن تتغير هذه القيمة أثناء تنفيذ البرنامج حسب اللغة وطريقة استخدامها.

General Example 
name = "Ammar"
age = 16
Explanation

في المثال السابق لدينا متغير باسم name يخزن اسمًا، ومتغير باسم age يخزن رقمًا.

فكرة المتغير واحدة بشكل عام، لكن طريقة إنشاء المتغير وكتابة الكود تختلف من لغة برمجة إلى أخرى.

Variable Parts
Name اسم نستخدمه للوصول إلى القيمة
Value البيانات المخزنة داخل المتغير
Data Type نوع البيانات في بعض لغات البرمجة
Assignment عملية إعطاء قيمة للمتغير
Example in C# 
int age = 16;
string name = "Ammar";
Example in JavaScript 
let age = 16;
let name = "Ammar";
Why Are Variables Important?

المتغيرات تسمح للبرنامج بتخزين البيانات واستخدامها وتعديلها أثناء تنفيذ العمليات المختلفة.
