CSS Term

Selector

محدد العناصر

Definition

Selector ما هو الـ

css في لتحديد عناصر التي نريد تطبيق التنسيق عليها. html هو الجزء الذي نستخدمه Selector الـ

Example 
p {
    color: red;
}
Explanation

p في المثال السابق هو Selector الـ

وهو يحدد جميع عناصر <p> الموجودة في الصفحة لتطبيق التنسيق عليها.

Common Selectors
p تحديد عناصر الفقرات
h1 تحديد العناوين
.card تحديد العناصر التي تحمل Class معين
#title تحديد عنصر يحمل ID معين
CSS Structure 
p {
    color: red;
}
