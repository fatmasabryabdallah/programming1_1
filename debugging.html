Programming Term

Debugging

تصحيح الأخطاء

Definition

Debugging ما هو الـ

الـ Debugging هو عملية البحث عن الأخطاء الموجودة في البرنامج وفهم سبب حدوثها ثم إصلاحها.

Example 
let number = 10;

console.log(numbre);
Explanation

في المثال السابق، كتبنا اسم المتغير بشكل خاطئ: numbre بدلًا من number.

اكتشاف الخطأ ومعرفة سببه وتصحيحه يعتبر جزءًا من عملية Debugging.

Common Error Types
Syntax Error خطأ في كتابة قواعد اللغة البرمجية
Logic Error الكود يعمل لكن النتيجة غير صحيحة
Runtime Error خطأ يحدث أثناء تشغيل البرنامج
Type Error خطأ مرتبط باستخدام نوع بيانات بطريقة غير مناسبة
Debugging Tools
Console عرض الرسائل والأخطاء ومراقبة القيم
Debugger أداة تساعد على فحص الكود أثناء التنفيذ
Breakpoints إيقاف تنفيذ البرنامج عند نقطة محددة
Error Message رسالة تساعد في معرفة مكان المشكلة
Correcting the Error 
let number = 10;

console.log(number);
Why Is Debugging Important?

Debugging يساعد المبرمج على اكتشاف المشكلات وإصلاحها والتأكد من أن البرنامج يعمل بالشكل المتوقع.
