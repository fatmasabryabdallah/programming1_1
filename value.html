CSS Term

Value

قيمة الخاصية

Definition

Value ما هي الـ

لتحديد الشكل أو السلوك الذي نريده للعنصر. Property هي القيمة التي نحددها للـ Value الـ

Example 
p {
    color: red;
}
Explanation

red في المثال السابق هي Value الـ

وبالتالي يتم تحديد لون النص ليكون أحمر. color هي Property بينما الـ

Common Values
red قيمة للون
20px قيمة للحجم أو المسافة
center قيمة لمحاذاة المحتوى
block قيمة لنوع عرض العنصر
CSS Structure 
p {
    color: red;
}
