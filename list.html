List

الـ List هي مجموعة من العناصر يمكن تخزين عدة قيم بداخلها في متغير واحد.

Definition

تستخدم List في Python لتخزين مجموعة من العناصر داخل متغير واحد، ويمكن أن تحتوي على أرقام أو نصوص أو أنواع مختلفة من البيانات.

Example 
names = ["Ali", "Ahmed", "Omar"]

print(names)
Explanation

في المثال السابق أنشأنا List باسم names ووضعنا بداخلها ثلاثة أسماء.

يتم كتابة عناصر الـ List بين [ ].

كل عنصر داخل الـ List يمتلك Index يبدأ من الرقم 0.

Accessing Elements 
names = ["Ali", "Ahmed", "Omar"]

print(names[0])
print(names[1])
print(names[2])

الناتج يكون:

Ali
Ahmed
Omar

Important Notes
[ ] تستخدم لإنشاء List.
Index يبدأ من 0.
Mutable يمكن تعديل عناصر الـ List.
Multiple Values يمكن تخزين عدة عناصر داخلها.
Common List Operations 
names = ["Ali", "Ahmed", "Omar"]

names[1] = "Ammar"

print(names)

يمكن تغيير قيمة عنصر داخل الـ List من خلال كتابة الـ Index الخاص به.
