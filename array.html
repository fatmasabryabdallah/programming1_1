JavaScript Term

Array

المصفوفة

Definition

Array ما هي الـ

هي بنية بيانات تُستخدم لتخزين مجموعة من القيم داخل متغير واحد. Array الـ

Example 
let fruits = ["Apple", "Banana", "Orange"];

console.log(fruits);
Explanation

ووضعنا بداخلها ثلاث قيم. Array باسم fruits في المثال السابق أنشأنا

0. من JavaScript ويبدأ العد في Index، كل قيمة لها رقم يسمى

Array Index
0 العنصر الأول
1 العنصر الثاني
2 العنصر الثالث
length عدد العناصر الموجودة داخل الـArray
Access Array Element 
let fruits = ["Apple", "Banana", "Orange"];

console.log(fruits[0]);
Common Array Methods
push() إضافة عنصر في نهاية الـArray
pop() حذف آخر عنصر
shift() حذف أول عنصر
unshift() إضافة عنصر في البداية
