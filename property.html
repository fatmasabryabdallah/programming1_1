CSS Term

Property

خاصية التنسيق

Definition

Property ما هي الـ

css هي الخاصية التي تحدد نوع التنسيق الذي نريد تطبيقه على العنصر في Property الـ

Example 
p {
    color: red;
}
Explanation

color في المثال السابق، هي Property الـ

سيكون هو القيمة المحددة لها. <p> وهي تحدد أن لون النص داخل عنصر

Common CSS Properties
color تحديد لون النص
background تحديد خلفية العنصر
font-size تحديد حجم الخط
margin تحديد المسافة الخارجية
CSS Structure 
p {
    color: red;
}
