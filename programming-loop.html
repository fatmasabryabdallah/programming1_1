Programming Term

Loop

حلقة التكرار

Definition

Loop ما هي الـ

الـ Loop هي طريقة تستخدم لتكرار مجموعة من التعليمات البرمجية أكثر من مرة حسب شرط أو عدد محدد.

General Example 
Start
  ↓
Repeat Instructions
  ↓
Check Condition
  ↓
Continue or Stop
Explanation

بدلًا من كتابة نفس الكود عدة مرات، نستخدم Loop لتكرار التعليمات تلقائيًا.

تستمر الحلقة في التنفيذ حتى يتحقق شرط التوقف أو ينتهي العدد المحدد من التكرارات.

Common Loops
for تكرار الكود بعدد أو شرط محدد
while التكرار طالما الشرط صحيح
do...while تنفيذ الكود مرة واحدة على الأقل ثم فحص الشرط
for...of التكرار على القيم في العناصر القابلة للتكرار
Example in C# 
for (int i = 1; i <= 5; i++)
{
    Console.WriteLine(i);
}
Example in JavaScript 
for (let i = 1; i <= 5; i++) {
    console.log(i);
}
Loop Structure
Start تحديد قيمة البداية
Condition تحديد متى يستمر التكرار
Update تغيير قيمة المتغير في كل دورة
Body التعليمات التي يتم تكرارها
Why Are Loops Important?

الحلقات تقلل تكرار الكود وتسمح بتنفيذ نفس المهمة لعدد كبير من العناصر أو المرات بسهولة.
