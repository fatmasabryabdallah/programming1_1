HTML Term

Element

HTML عنصر

Definition

Element ما هو الـ

ويُستخدم لبناء المحتوى وتحديد نوعه داخل الصفحة. HTML هو مكوّن من مكونات صفحة Element الـ

Example 
<p>Hello World</p>
Explanation

HTML يمثل فقرة في صفحة <p> في المثال السابق، العنصر

ويتكون العنصر من وسم البداية، والمحتوى، ووسم النهاية.

Element Parts
<p> وسم البداية
Hello World المحتوى
</p> وسم النهاية
Element العنصر كاملًا
