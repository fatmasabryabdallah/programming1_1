JavaScript Term

Loop

حلقة التكرار

Definition

Loop ما هي الـ

هي طريقة لتكرار مجموعة من التعليمات البرمجية عدة مرات حسب شرط أو عدد محدد. Loop الـ

Example 
for (let i = 1; i <= 5; i++) {
    console.log(i);
}
Explanation

لتكرار الكود. for في المثال السابق استخدمنا

يبدأ المتغير i من 1، ويستمر التكرار طالما أن i <= 5، ثم تزيد قيمة i بمقدار 1 في كل مرة.

Common Loops
for تكرار الكود بعدد أو شرط محدد
while التكرار طالما الشرط صحيح
do...while ينفذ الكود مرة واحدة على الأقل
for...of التكرار على قيم العناصر القابلة للتكرار
Another Example 
let fruits = ["Apple", "Banana", "Orange"];

for (let fruit of fruits) {
    console.log(fruit);
}
