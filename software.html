Computer Term

Software

البرمجيات

Definition

Software ما هو الـ

هو مجموعة البرامج والتعليمات التي تخبر الكمبيوتر بما يجب عليه فعله وكيفية تنفيذ المهام.

Examples 
Operating System
Web Browser
Code Editor
Games
Applications
Explanation

على عكس الـHardware، لا يمكن لمس الـSoftware لأنه يتكون من برامج وتعليمات تعمل على الكمبيوتر.

يحتاج الكمبيوتر إلى Software لكي يستطيع المستخدم تشغيل البرامج وتنفيذ المهام المختلفة.

Main Software Types
System Software برامج تساعد على تشغيل وإدارة الكمبيوتر
Application Software برامج يستخدمها المستخدم لتنفيذ مهام معينة
Programming Software أدوات تساعد المبرمج على كتابة واختبار الكود
Utility Software برامج تساعد في صيانة وإدارة الجهاز
Examples of System Software
Windows نظام تشغيل
Linux نظام تشغيل
macOS نظام تشغيل
Device Drivers برامج تساعد النظام على التعامل مع الأجهزة
Hardware vs Software
Hardware مكونات مادية يمكن لمسها
Software برامج وتعليمات تعمل على الجهاز

Why Is Software Important?

الـSoftware هو الذي يوفر التعليمات والبرامج اللازمة لاستخدام الكمبيوتر وتنفيذ المهام المختلفة.
