Dictionary

الـ Dictionary تستخدم لتخزين البيانات في صورة Key و Value.

Definition

الـ Dictionary هي نوع من أنواع البيانات في Python، وتستخدم لتخزين البيانات على شكل أزواج من Key و Value.

كل Key يتم ربطه بقيمة معينة يمكن الوصول إليها باستخدام اسم الـ Key.

Example 
student = {
    "name": "Ammar",
    "age": 16,
    "grade": "Second Secondary"
}

print(student)

في المثال السابق أنشأنا Dictionary باسم student وتحتوي على بيانات الطالب.

Key & Value

في هذا السطر: 

"name": "Ammar"

name هو الـ Key، بينما Ammar هي الـ Value.

Access Value 
student = {
    "name": "Ammar",
    "age": 16
}

print(student["name"])
print(student["age"])

للوصول إلى قيمة معينة نكتب اسم الـ Key داخل الأقواس المربعة [ ].

Modify 
student = {
    "name": "Ammar",
    "age": 16
}

student["age"] = 17

print(student)

يمكن تعديل قيمة موجودة عن طريق كتابة الـ Key ثم إعطائه قيمة جديدة.

Important Notes
Key اسم أو مفتاح نستخدمه للوصول إلى البيانات.
Value القيمة المرتبطة بالـ Key.
{ } تستخدم لإنشاء Dictionary.
[ ] تستخدم للوصول إلى قيمة باستخدام الـ Key.
Multiple Data 
car = {
    "brand": "BMW",
    "model": "M4",
    "year": 2025
}

print(car["brand"])
print(car["model"])
print(car["year"])

يمكن للـ Dictionary تخزين عدة بيانات مختلفة داخل نفس المتغير باستخدام Keys مختلفة.
