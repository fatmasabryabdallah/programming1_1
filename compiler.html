Programming Term

Compiler

المترجم البرمجي

Definition

Compiler ما هو الـ

الـ Compiler هو برنامج أو أداة تقوم بترجمة الكود المكتوب بلغة برمجة إلى صيغة يمكن للنظام أو بيئة التشغيل تنفيذها، حسب اللغة ونظامها.

Simple Idea 
Source Code
     ↓
 Compiler
     ↓
Translated Program
Explanation

المبرمج يكتب الكود المصدري باستخدام لغة برمجة، ثم تقوم أداة الترجمة بمعالجته وفق آلية اللغة.

في بعض اللغات ينتج عن عملية الترجمة ملف أو صيغة وسيطة أو قابلة للتنفيذ، حسب التقنية المستخدمة.

Compiler Tasks
Check Syntax فحص القواعد البرمجية للكود
Analyze Code تحليل الكود واكتشاف بعض المشكلات
Translate ترجمة الكود إلى تمثيل مناسب للتنفيذ
Optimize إجراء تحسينات على الكود في بعض الأنظمة
Example in C# 
int number = 10;

Console.WriteLine(number);
Compiler vs Interpreter
Compiler يترجم البرنامج وفق نموذج تنفيذ اللغة قبل التنفيذ أو ضمن مرحلة ترجمة
Interpreter ينفذ التعليمات باستخدام آلية تفسير أثناء التشغيل
Why Is It Important?

أدوات الترجمة جزء أساسي من كثير من لغات البرمجة، لأنها تربط بين الكود الذي يكتبه المبرمج وطريقة تنفيذ البرنامج.
