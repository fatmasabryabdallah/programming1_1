Computer Term

Storage

تخزين البيانات

Definition

Storage ما هو الـ

الـ Storage هو المكان الذي تُخزن فيه الملفات والبرامج والبيانات بحيث تبقى محفوظة حتى بعد إيقاف تشغيل الكمبيوتر.

Examples 
SSD
HDD
USB Flash Drive
Memory Card
Explanation

عندما تحفظ صورة أو ملفًا أو تثبّت برنامجًا، يتم تخزين البيانات على وسيلة تخزين مثل SSD أو HDD.

يختلف Storage عن RAM في أن البيانات الموجودة على وسيلة التخزين لا تختفي بمجرد إيقاف تشغيل الجهاز.

Types of Storage
SSD وحدة تخزين سريعة تعتمد على الذاكرة الفلاش
HDD وحدة تخزين تعتمد على أقراص مغناطيسية
USB Flash Drive وحدة تخزين محمولة
Memory Card وسيلة تخزين صغيرة للأجهزة المختلفة
Storage Uses
Files تخزين الصور والمستندات والملفات
Programs تخزين البرامج والتطبيقات
Operating System تخزين ملفات نظام التشغيل
Backup حفظ نسخ احتياطية من البيانات
Storage vs RAM
Storage يحفظ البيانات بشكل دائم أو طويل الأمد
RAM تخزن البيانات مؤقتًا أثناء تشغيل البرامج
Simple Idea 
Save File
    ↓
Storage
    ↓
Keep Data
    ↓
Open File Later
Why Is Storage Important?

التخزين يسمح بحفظ الملفات والبرامج والبيانات والاحتفاظ بها لاستخدامها لاحقًا.
