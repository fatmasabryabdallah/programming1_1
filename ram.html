Computer Term

RAM

Random Access Memory

Definition

RAM ما هي الـ

RAM هي اختصار لـ Random Access Memory، وهي ذاكرة سريعة ومؤقتة يستخدمها الكمبيوتر لتخزين البيانات والتعليمات التي تحتاجها البرامج أثناء التشغيل.

Simple Idea 
Open Program
     ↓
Load Data into RAM
     ↓
CPU Uses the Data
     ↓
Program Runs
Explanation

عندما تفتح برنامجًا، يتم تحميل البيانات والتعليمات التي يحتاجها إلى الذاكرة لتتمكن وحدة المعالجة من الوصول إليها بسرعة.

RAM ذاكرة متطايرة، أي أن البيانات الموجودة فيها لا تبقى بعد إيقاف تشغيل الجهاز.

RAM Characteristics
Temporary تخزين مؤقت أثناء تشغيل الجهاز
Fast توفر وصولًا سريعًا للبيانات
Volatile تفقد محتواها عند انقطاع الطاقة
Active Programs تخزن بيانات البرامج التي تعمل حاليًا
RAM vs Storage
RAM ذاكرة مؤقتة وسريعة تستخدم أثناء تشغيل البرامج
Storage تخزين دائم نسبيًا للملفات والبرامج
RAM vs CPU
RAM توفر البيانات والتعليمات التي تحتاجها البرامج أثناء التشغيل
CPU ينفذ التعليمات ويعالج البيانات
Example 
Program
  ↓
RAM
  ↓
CPU
  ↓
Result
Why Is RAM Important?

RAM توفر مساحة سريعة للبيانات والتعليمات التي تحتاجها البرامج أثناء التشغيل، ولذلك تؤثر سعة الذاكرة وتوفرها في قدرة الجهاز على التعامل مع عدة مهام وبرامج في الوقت نفسه.
