JavaScript Term

DOM

Document Object Model

Definition

DOM ما هو الـ

الـ DOM هو نموذج يمثل عناصر صفحة HTML على شكل شجرة من الكائنات، ويسمح لـ JavaScript بالوصول إلى هذه العناصر والتعامل معها.

Example 
const title = document.getElementById("title");

title.textContent = "Hello World";
Explanation

استخدمنا getElementById() للوصول إلى عنصر HTML يحمل الـID title.

ثم استخدمنا textContent لتغيير النص الموجود داخل العنصر.

Common DOM Methods
getElementById() الوصول إلى عنصر باستخدام ID
querySelector() الوصول إلى أول عنصر يطابق Selector
querySelectorAll() الوصول إلى مجموعة من العناصر
getElementsByClassName() الوصول إلى عناصر تحمل Class معين
Changing an Element 
const title = document.querySelector("h1");

title.style.color = "red";
DOM Structure 
HTML
 └── body
      ├── h1
      ├── p
      └── button
