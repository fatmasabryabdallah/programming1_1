JavaScript Term

Function

الدالة

Definition

Function ما هي الـ

هي مجموعة من التعليمات البرمجية نضعها داخل وحدة يمكن استدعاؤها لتنفيذ مهمة معينة. Function الـ

Example 
function sayHello() {
    console.log("Hello");
}

sayHello();
Explanation

console.log(). ووضعنا داخلها أمر sayHello باسم Function أنشأنا

لتنفيذ التعليمات الموجودة بداخلها. sayHello() بعد ذلك استدعينا الدالة باستخدام

Function Parts
function الكلمة المستخدمة لإنشاء الدالة
sayHello اسم الدالة
() المكان الذي يمكن وضع Parameters بداخله
{ } تحتوي على التعليمات البرمجية
Function with Parameter 
function greet(name) {
    console.log("Hello " + name);
}

greet("Ammar");
