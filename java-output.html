Output

الـ Output يستخدم لعرض البيانات والنتائج على الشاشة.

Definition

الـ Output هو عرض البيانات أو الرسائل التي ينتجها البرنامج للمستخدم.

في Java نستخدم بشكل أساسي System.out.print() و System.out.println() لعرض البيانات.

System.out.println() 
System.out.println("Hello World");
System.out.println("Welcome to Java");

تستخدم System.out.println() لطباعة البيانات ثم الانتقال إلى سطر جديد.

System.out.print() 
System.out.print("Hello ");
System.out.print("World");

تستخدم System.out.print() لطباعة البيانات دون الانتقال إلى سطر جديد.

print vs println
System.out.print() تطبع البيانات وتبقى في نفس السطر.
System.out.println() تطبع البيانات ثم تنتقل إلى سطر جديد.
Output with Variable 
String name = "Ammar";
int age = 16;

System.out.println(name);
System.out.println(age);

يمكن استخدام الـ Output لعرض القيم المخزنة داخل المتغيرات.

Multiple Output 
System.out.println("Name: Ammar");
System.out.println("Age: 16");
System.out.println("Student: true");

يمكن استخدام أكثر من أمر طباعة لعرض عدة بيانات للمستخدم.

Concatenation 
String name = "Ammar";
int age = 16;

System.out.println("Name: " + name);
System.out.println("Age: " + age);

يمكن دمج النصوص مع قيم المتغيرات باستخدام علامة +.

Important Notes
print() تطبع في نفس السطر.
println() تطبع ثم تنتقل إلى سطر جديد.
System.out يستخدم لعرض البيانات على الشاشة.
+ يستخدم لدمج النصوص مع القيم.
