Condition

الـ Condition تستخدم لاتخاذ قرار معين بناءً على نتيجة الشرط.

Definition

الـ Condition هي عبارة شرطية تجعل البرنامج ينفذ أوامر مختلفة حسب نتيجة الشرط.

في C# نستخدم بشكل أساسي if و else if و else.

If Statement 
int age = 18;

if (age >= 18)
{
    Console.WriteLine("Adult");
}

إذا كان الشرط age >= 18 صحيحًا، فسيتم تنفيذ الكود الموجود داخل الـ if.

If / Else 
int age = 16;

if (age >= 18)
{
    Console.WriteLine("Adult");
}
else
{
    Console.WriteLine("Not Adult");
}

إذا كان الشرط صحيحًا يتم تنفيذ جزء if، وإذا كان غير صحيح يتم تنفيذ else.

Else If 
int grade = 85;

if (grade >= 90)
{
    Console.WriteLine("Excellent");
}
else if (grade >= 75)
{
    Console.WriteLine("Very Good");
}
else
{
    Console.WriteLine("Good");
}

نستخدم else if عندما نريد اختبار شرط آخر بعد الشرط الأول.

Comparison Operators
== يساوي.
!= لا يساوي.
> أكبر من.
< أصغر من.
>= أكبر من أو يساوي.
<= أصغر من أو يساوي.
Multiple Conditions 
int age = 20;
bool hasId = true;

if (age >= 18 && hasId)
{
    Console.WriteLine("Access Granted");
}
else
{
    Console.WriteLine("Access Denied");
}

يمكن استخدام أكثر من شرط معًا باستخدام && و || للوصول إلى قرار أكثر دقة.

Logical Operators
&& AND: يجب أن يكون الشرطان صحيحين.
|| OR: يكفي أن يكون أحد الشرطين صحيحًا.
! NOT: تعكس القيمة المنطقية.
Practical Example 
int mark = 80;

if (mark >= 50)
{
    Console.WriteLine("Pass");
}
else
{
    Console.WriteLine("Fail");
}

في هذا المثال إذا كانت الدرجة 50 أو أكثر تكون النتيجة Pass، وإلا تكون Fail.

Important Notes
if لاختبار الشرط الأساسي.
else if لاختبار شرط إضافي.
else تعمل عندما تكون الشروط السابقة غير صحيحة.
if (condition) يجب كتابة الشرط بين الأقواس.
