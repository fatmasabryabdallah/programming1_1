Java

Java هي لغة برمجة متعددة الاستخدامات تستخدم في تطوير أنواع مختلفة من التطبيقات.

Definition

Java هي لغة برمجة عالية المستوى تعتمد على البرمجة الكائنية وتستخدم في تطوير العديد من أنواع البرامج والتطبيقات.

تتميز Java بإمكانية تشغيل البرامج على أنظمة مختلفة من خلال Java Virtual Machine.

Example 
public class Main {

    public static void main(String[] args) {

        System.out.println("Hello World");

    }

}

هذا المثال يطبع النص Hello World باستخدام System.out.println().

Explanation

في Java يكون الكود داخل class.

يبدأ تنفيذ البرنامج عادةً من الدالة main().

تستخدم System.out.println() لطباعة البيانات على الشاشة.

Main Method 
public static void main(String[] args)
{
    // Program starts here
}

تعتبر main() نقطة البداية لتنفيذ برنامج Java.

Uses
Desktop Apps تستخدم Java في إنشاء بعض تطبيقات سطح المكتب.
Web Development تستخدم في تطوير تطبيقات الويب.
Android كانت Java من اللغات الأساسية لتطوير تطبيقات Android.
Enterprise Apps تستخدم في بناء تطبيقات وأنظمة المؤسسات.
Variable Example 
int age = 16;
String name = "Ammar";

System.out.println(name);
System.out.println(age);

يمكن في Java إنشاء Variables لتخزين البيانات، مع تحديد نوع البيانات قبل اسم المتغير.

Important Notes
Java لغة برمجة متعددة الاستخدامات.
class تستخدم لتعريف Class في Java.
main() نقطة بداية تنفيذ البرنامج.
System.out.println() تستخدم لطباعة البيانات.
