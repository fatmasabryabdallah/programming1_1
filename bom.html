JavaScript Term

BOM

Browser Object Model

Definition

BOM ما هو الـ

BOM اختصار لـ Browser Object Model، وهو مجموعة من الكائنات التي يوفرها المتصفح للتعامل مع نافذة المتصفح ومعلوماتها.

Example 
window.alert("Hello World");
Explanation

في المثال السابق استخدمنا window للوصول إلى نافذة المتصفح.

ثم استخدمنا alert() لإظهار رسالة للمستخدم.

Common BOM Objects
window يمثل نافذة المتصفح
location الوصول إلى معلومات عنوان الصفحة والتنقل
history التعامل مع سجل التصفح
navigator الوصول إلى معلومات عن المتصفح
screen الوصول إلى معلومات عن شاشة المستخدم
document يمثل صفحة HTML ويتم التعامل معه غالبًا عبر DOM
Location Example 
console.log(location.href);
History Example 
history.back();
BOM vs DOM
BOM التعامل مع المتصفح ونافذته
DOM التعامل مع عناصر صفحة HTML
