Programming Term

Condition

الشرط

Definition

Condition ما هي الـ

الـ Condition هي طريقة تُستخدم لجعل البرنامج يتخذ قرارًا بناءً على نتيجة شرط معين.

General Example 
If age is greater than or equal to 18
    Allow access
Else
    Deny access
Explanation

البرنامج يفحص شرطًا معينًا، ثم يحدد الكود الذي سيتم تنفيذه بناءً على نتيجة الشرط.

إذا كان الشرط صحيحًا يتم تنفيذ أمر معين، وإذا كان غير صحيح يمكن تنفيذ أمر آخر.

Common Condition Statements
if تنفيذ كود عند تحقق الشرط
else تنفيذ كود بديل عندما لا يتحقق الشرط
else if اختبار شرط إضافي
switch اختيار حالة من عدة حالات
Example in C# 
int age = 18;

if (age >= 18)
{
    Console.WriteLine("Allowed");
}
else
{
    Console.WriteLine("Denied");
}
Example in JavaScript 
let age = 18;

if (age >= 18) {
    console.log("Allowed");
} else {
    console.log("Denied");
}
Comparison Operators
== مقارنة القيم في لغات تدعم هذا العامل
=== مقارنة القيمة والنوع في JavaScript
> أكبر من
< أصغر من
>= أكبر من أو يساوي
<= أصغر من أو يساوي
Why Are Conditions Important?

الشروط تسمح للبرنامج باتخاذ قرارات مختلفة والتعامل مع الحالات المتنوعة أثناء التنفيذ.
