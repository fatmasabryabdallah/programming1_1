JavaScript Term

Event

الحدث

Definition

Event ما هو الـ

الـ Event هو حدث يحدث في صفحة الويب، ويمكن لـ JavaScript اكتشافه وتنفيذ كود عند حدوثه.

Example 
button.addEventListener("click", function () {
    console.log("Button clicked");
});
Explanation

في المثال السابق استخدمنا addEventListener() لمراقبة حدث الضغط على الزر.

عند الضغط على الزر يتم تنفيذ الدالة، وفي المثال تظهر رسالة داخل الـConsole.

Common Events
click عند الضغط على العنصر
mouseover عند تحريك المؤشر فوق العنصر
input عند تغيير قيمة حقل الإدخال
submit عند إرسال النموذج
Another Example 
const button = document.querySelector("button");

button.addEventListener("click", function () {
    alert("Hello!");
});
