Data Type

الـ Data Type يحدد نوع البيانات التي يمكن تخزينها داخل المتغير.

Definition

الـ Data Type هو نوع البيانات الذي يحدد نوع القيمة التي يمكن تخزينها داخل الـ Variable.

في C# يجب تحديد نوع البيانات عند إنشاء المتغير حتى تعرف اللغة نوع القيمة التي سيتم تخزينها.

int 
int age = 16;

Console.WriteLine(age);

int تستخدم لتخزين الأعداد الصحيحة مثل 10 و 25 و 100.

float 
float height = 1.75f;

Console.WriteLine(height);

float تستخدم لتخزين الأعداد العشرية، ويضاف الحرف f عادةً إلى القيمة العشرية من نوع float.

double 
double price = 99.99;

Console.WriteLine(price);

double تستخدم أيضًا للأعداد العشرية وتوفر دقة أعلى من float في الاستخدامات المعتادة.

string 
string name = "Ammar";

Console.WriteLine(name);

string تستخدم لتخزين النصوص، ويتم كتابة النص داخل علامات الاقتباس.

char 
char grade = 'A';

Console.WriteLine(grade);

char تستخدم لتخزين حرف واحد فقط، ويكتب الحرف داخل علامات الاقتباس المفردة.

bool 
bool isStudent = true;

Console.WriteLine(isStudent);

bool تستخدم لتخزين قيمة منطقية، وتكون إما true أو false.

Common Data Types
int لتخزين الأعداد الصحيحة.
float لتخزين الأعداد العشرية.
double لتخزين الأعداد العشرية بدقة أعلى.
string لتخزين النصوص.
char لتخزين حرف واحد.
bool لتخزين true أو false.
Multiple Data Types 
string name = "Ammar";
int age = 16;
float height = 1.75f;
char grade = 'A';
bool isStudent = true;

Console.WriteLine(name);
Console.WriteLine(age);
Console.WriteLine(height);
Console.WriteLine(grade);
Console.WriteLine(isStudent);

يمكن استخدام أكثر من Data Type داخل نفس البرنامج، حسب نوع البيانات التي نحتاج إلى تخزينها.

Important Notes
int أعداد صحيحة.
float أعداد عشرية.
string نصوص.
char حرف واحد.
bool true أو false.
