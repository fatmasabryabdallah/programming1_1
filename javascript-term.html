Programming Language

JavaScript

لغة برمجة للويب

Definition

JavaScript ما هي

هي لغة برمجة تُستخدم لإضافة التفاعل والسلوك الديناميكي إلى صفحات ومواقع الويب. JavaScript

Example 
let message = "Hello World";

console.log(message);
Explanation

"Hello World". ووضعنا داخله النص message في المثال السابق أنشأنا متغيرًا باسم

console لعرض قيمة المتغير في الـ console.log() ثم استخدمنا

JavaScript Uses
Interactive Websites إضافة التفاعل إلى صفحات الويب
DOM التعامل مع عناصر HTML
Events التعامل مع الضغط والكتابة والأحداث
Data التعامل مع البيانات والمنطق البرمجي
Basic Structure 
let name = "Ammar";

console.log(name);
