Programming Term

Data Type

نوع البيانات

Definition

Data Type ما هو الـ

الـ Data Type هو النوع الذي يحدد طبيعة البيانات التي يتم تخزينها أو التعامل معها داخل البرنامج.

Example 
Age = 16
Name = "Ammar"
IsStudent = true
Explanation

في المثال السابق لدينا أنواع مختلفة من البيانات: رقم، ونص، وقيمة منطقية.

نوع البيانات يساعد البرنامج على معرفة طبيعة القيمة وكيفية التعامل معها.

Common Data Types
Integer الأعداد الصحيحة مثل 10 و 25
Float / Double الأعداد التي تحتوي على كسور عشرية
String النصوص مثل "Hello"
Boolean قيمة منطقية مثل true أو false
Character حرف واحد في اللغات التي تدعم هذا النوع
Array مجموعة من القيم يتم تخزينها معًا
Example in C# 
int age = 16;
float height = 1.75f;
string name = "Ammar";
bool isStudent = true;
char grade = 'A';
Example in JavaScript 
let age = 16;
let height = 1.75;
let name = "Ammar";
let isStudent = true;
Why Is Data Type Important?

فهم أنواع البيانات يساعد المبرمج على اختيار الطريقة المناسبة لتخزين القيم ومعالجتها داخل البرنامج.
