HTML Term

ID

المعرّف الفريد

Definition

ID ما هو الـ

يمكن من خلاله تحديد هذا العنصر. Attribute يُستخدم لإعطاء عنصر HTML معرّفًا فريدًا ID الـ

Example 
<h1 id="main-title">
    Welcome
</h1>
Explanation

في المثال السابق Id هي قيمه الـ main-title.

CSS أو JavaScript للوصول إلى هذا العنصر.ويستخدم مع ID لتحديد عنصر معين، ويمكن استخدامه

ID Examples
#header تحديد الهيدر
#main تحديد المحتوى الرئيسي
#footer تحديد الفوتر
#title تحديد عنصر معين
