JavaScript Term

Object

الكائن

Definition

Object ما هو الـ

باستخدام مجموعة من الخصائص والقيم. JavaScript هو طريقة لتنظيم البيانات داخل Object الـ

Example 
let student = {
    name: "Ammar",
    age: 16,
    student: true
};
Explanation

student. باسم Object في المثال السابق أنشأنا

ولكل خاصية قيمة خاصة بها. age و student، و name يحتوي على خصائص مثل

Object Parts
name اسم الخاصية
"Ammar" قيمة الخاصية
age خاصية تخزن العمر
16 قيمة خاصية age
Access Object Property 
let student = {
    name: "Ammar",
    age: 16
};

console.log(student.name);
console.log(student.age);
Another Way 
console.log(student["name"]);
