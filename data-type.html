JavaScript Term

Data Type

نوع البيانات

Definition

Data Type ما هو الـ

هو نوع القيمة التي يتعامل معها البرنامج، مثل النصوص والأرقام والقيم المنطقية. Data Type الـ

Example 
let name = "Ammar";
let age = 16;
let isStudent = true;
Explanation

في المثال السابق، كل متغير يحتوي على نوع مختلف من البيانات.

قيمة منطقية.و 16 رقم true نص، و "Ammar"

Common Data Types
String النصوص مثل "Hello"
Number الأرقام مثل 10 و 25.5
Boolean قيمة منطقية: true أو false
Undefined متغير لم يتم إعطاؤه قيمة
Null قيمة تمثل عدم وجود قيمة مقصودة
Object بيانات منظمة على شكل خصائص وقيم

let age = 16;
